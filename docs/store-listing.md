## 详细描述

哔哩喵（Bili-Mux）是一款浏览器扩展，帮助你在观看 B站视频时进行个人留存与离线归档。所有处理均在浏览器内完成，无需安装任何本地软件。

### 核心功能

🎬 **封面保存** — 一键保存视频封面图，原始分辨率

📦 **音视频流分离保存** — DASH 格式下视频与音频各自独立，支持保存原始画质（最高 4K）的视频流与音频流

🎞️ **浏览器内合成 MP4** — 利用 ffmpeg.wasm 在浏览器后台将分离的音视频流封装为单个 MP4 文件，无需在电脑上安装 ffmpeg，合成进度实时可见

📺 **FLV 合并留存** — 旧版 HTTP-FLV 格式直接合并为可播放文件，体积更小、速度更快

📋 **分P批量处理** — 勾选多个分P逐个留存，省去重复操作

📊 **实时资源监控** — 面板内显示当前内存占用与网络速率

### 使用方式

1. 打开任意 B站视频页（需已登录）
2. 点击视频工具栏末尾的粉色「下载」按钮展开面板
3. 选择功能：合成 MP4 / 分离保存 / FLV 合并 / 分P批量
4. 完成后文件自动保存到浏览器默认下载目录

### 技术特点

- 纯浏览器端运行，无后端服务器，不收集任何用户数据
- 合成 MP4 使用 ffmpeg.wasm（Offscreen Document API），不影响页面操作
- 多标签页隔离，不同视频的合成任务互不干扰
- 已适配 B站 WBI 签名机制，确保接口请求合法

### 仅供个人留存

本工具仅解析用户账号已有权观看的视频流，用于个人学习、离线观看与归档。请勿用于批量搬运或二次分发。使用者须自行遵守所在地区的版权法规及 B站用户协议。

## 权限说明（审核填写用）

| 权限 | 用途说明 |
|------|----------|
| downloads | 将用户选择留存的视频、音频、封面文件保存至本地下载目录 |
| declarativeNetRequestWithHostAccess | 为 bilivideo.com 域的媒体请求注入 Referer 头，使媒体流可正常获取 |
| content_scripts（声明式注入，无需 scripting 权限） | 在 bilibili.com 视频页 / 稍后再看等 /list/* 播放页注入留存操作面板，供用户选择清晰度与留存方式 |
| offscreen | 创建 Offscreen Document 运行 ffmpeg.wasm，在后台完成音视频流封装 |
| host_permissions: bilibili.com | 调用 B站 API 获取视频信息与播放地址（使用用户已有登录态） |
| host_permissions: bilivideo.com | 获取媒体流数据用于本地留存 |
| host_permissions: hdslb.com | 获取视频封面图片 |
