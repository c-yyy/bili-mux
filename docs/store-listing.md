## 详细描述

哔哩喵（Bili-Mux）是一款浏览器扩展，让你在看 B站时把喜欢的视频轻松保存下来、离线观看。不用装任何软件，也不用懂技术，点几下就能完成。

### 能做什么

🎬 **保存视频** — 一键把视频存成 MP4 文件，画质最高可选 4K，全程在浏览器里完成

🖼️ **保存封面** — 一键存下视频封面图，原图清晰度

🎵 **单独保存声音 / 画面** — 视频和声音分开保存，只留音频、或只留画面都行

📺 **番剧、课程也能存** — 不只普通视频，追的番剧、买的课程（需账号有观看权限）同样能保存，还能切换「选集」存想存的那一集

📚 **多集批量** — 勾选多个分P，自动逐集保存，不用一集集手动点

### 为什么选哔哩喵

✨ **开箱即用** — 装好后，B站视频页的工具栏上会出现粉色「下载」按钮，点一下展开面板即可用，无需配置

🔒 **全程本地、不上传** — 所有解析与合成都在你自己的浏览器里完成，不经过任何服务器，不上传任何数据

🧩 **无需额外软件** — 视频合成直接在浏览器内完成，不用另外安装 ffmpeg 之类的工具

🎯 **用你自己的账号** — 只保存你账号本来就有权观看的内容，清晰度取决于你能看到哪一档

### 使用方法

1. 打开任意 B站视频页（需已登录），点击视频工具栏的粉色「下载」按钮
2. 想存 MP4：选好清晰度 → 点「合成 MP4」→ 等进度条走完，文件自动保存
3. 想单独存画面或声音：点对应的保存按钮即可
4. 追番剧、看课程：打开番剧或课程页面，同样点「下载」按钮，用「选集」选想保存的那一集

### 仅供个人留存

本工具仅保存你账号本来就有权观看的内容，用于个人学习、离线观看与归档。请勿用于批量搬运或二次分发，由此产生的版权与账号风险由使用者自行承担。

## 权限说明（审核填写用）

| 权限 | 用途说明 |
|------|----------|
| downloads | 将用户选择留存的视频、音频、封面文件保存至本地下载目录 |
| declarativeNetRequestWithHostAccess | 为 bilivideo.com 域的媒体请求注入 Referer 头，使媒体流可正常获取 |
| content_scripts（声明式注入，无需 scripting 权限） | 在 bilibili.com 视频页 / 稍后再看等 /list/* 播放页 / 番剧页（/bangumi/play/*）/ 课程页（/cheese/play/*）注入留存操作面板，供用户选择清晰度与留存方式 |
| offscreen | 创建 Offscreen Document 运行 ffmpeg.wasm，在后台完成音视频流封装 |
| **web_accessible_resources：仅 icons/icon128.png，且限定 bilibili.com** | 面板左上角显示扩展图标。**不含任何脚本**：ffmpeg.wasm 全套（含 wasm 与 worker）随扩展包体分发，仅在 Offscreen Document（扩展自有页面 chrome-extension://）内加载，不对外暴露、不注入任何网页 |
| host_permissions: bilibili.com | 调用 B站 API 获取视频信息与播放地址（使用用户已有登录态） |
| host_permissions: bilivideo.com | 获取媒体流数据用于本地留存 |
| host_permissions: bilivideo.cn | 获取媒体流数据（备用 CDN 域名） |
| host_permissions: hdslb.com | 获取视频封面图片 |
